## 文档导航

本文档体系为火宝短剧AI短剧生成平台提供完整的知识库。遵循**cn-doc-writer**技能的专家级标准设计，文档被精心组织为三大模块，以满足不同用户的需求。无论你是初次接触平台的新手用户，还是希望深入开发的高级工程师，都能在这里找到适合你的学习路径和参考资料。

文档体系采用**三条并行学习路径**的设计：**快速入门/用户手册**帮助你快速上手使用平台功能，**开发手册**指导你进行二次开发和功能扩展，**专家指南**则深入系统内部帮助你理解底层原理。

### 学习路径选择指南

```
Q: 你的主要目标是什么？

├── 我是新用户，想快速学会使用平台制作短剧
│   └── → 选择「快速入门 / 命令手册」→ 了解如何操作
│
├── 我是开发者，想参与平台开发或熟悉代码
│   └── → 选择「开发手册」→ 快速进入开发状态
│
└── 我是高级工程师，想深入理解底层原理，成为专家
    └── → 选择「专家指南」→ 掌握系统架构与设计
```
