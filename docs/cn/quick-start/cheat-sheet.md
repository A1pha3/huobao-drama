## 💻 开发者与部署命令手册

如果你是开发者或需要自行部署服务的用户，请参考以下核心命令。所有命令均在项目根目录下执行。

### 1. 后端服务 (Go)

```bash
# 运行后端（开发模式，默认端口 5678）
go run main.go

# 编译为生产环境二进制文件
go build -o huobao-drama .

# 运行数据库迁移（通常在启动时自动完成）
go run cmd/migrate/main.go

# 运行后端测试
go test ./...
```

### 2. 前端服务 (Vue 3 + Vite)

```bash
# 进入前端目录
cd web

# 安装依赖
npm install

# 运行前端开发服务器（默认端口 3012，带热重载）
npm run dev

# 构建前端生产环境静态文件
npm run build
```

### 3. Docker 部署命令

```bash
# 编译并启动所有服务（后台运行）
docker compose up -d --build

# 实时查看服务日志
docker compose logs -f

# 停止并移除容器
docker compose down
```

## 🎨 用户界面操作速查表

如果你是创作者，以下是你在 Web 界面中最常用的操作路径和快捷功能。

### 核心创作工作流

| 目标 | 操作路径 | 提示与技巧 |
|------|----------|------------|
| **创建新剧本** | 首页 -> `新建项目` -> 填写项目信息 -> `创建` | 推荐使用 **AI辅助生成** 输入一句话创意快速起步。 |
| **设计角色** | 项目详情页 -> 顶部 `角色` 标签 -> `添加角色` | 描述越详细（如：17岁，白衬衫，黑框眼镜），生成的形象越精准。 |
| **生成分镜** | 剧本页面 -> 确认无误后点击 `生成分镜` | 系统会批量处理。如遇个别失败，可点击对应分镜单独 `重新生成`。 |
| **合成视频** | 分镜列表 -> 选中目标分镜 -> `生成视频` | 可多选分镜批量生成；生成前可调整分辨率和帧率等参数。 |

### 常见问题排查操作

| 遇到问题 | 对应操作 |
|----------|----------|
| **AI生成结果不满意** | 修改提示词/描述 -> 点击卡片上的 `重新生成`。 |
| **找不到历史项目** | 返回首页 -> 查看 `项目列表`（按最近修改时间排序）。 |
| **视频生成一直失败** | 检查后台 `FFmpeg` 是否正确安装；检查本地磁盘空间是否充足。 |

> **💡 专家提示**：在编写剧本提示词时，遵循 **"身份设定 + 核心冲突 + 期望风格"** 的公式（例如：“一个高中生意外获得超能力（冲突），整体风格轻松幽默（风格）”），能大幅提升 AI 生成剧本的可用性。
